相机扫码后选 Sileo 或 Irisin

  • Sileo 打开
  • Irisin 添加
  • Zebra 需手动粘贴（客户端未实现一键）
手动添加步骤
  1. 打开客户端的「源」，点右上角 +
  2. 粘贴上面的地址并保存
  3. 回到源列表下拉刷新，插件即出现
命令行方式 
apt update
apt install <包名>
